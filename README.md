# 千幕


🎬 一个 SillyTavern 第三方界面扩展，做你故事的**幕后导演**：埋线推演、递送创作灵感，不设定向日程与线性叙事路径，不替User做选择，最大化叙事自由度与演变弹性。

---

## ✨ 它能做什么

### 🎬 推演 —— 让世界自主运转

- 🪡 **暗线灵感池** · 推演下一幕的任务、因果链、角色动向与世界回声，提炼为线索后台注入正文，正文中自然触发取用。
- 🌍 **世界自运转** · NPC与事件各有独立运行逻辑，User可介入推动、可旁观见证、可全然不知；褪去主角光环，让故事拥有真实的生长质感。
- 🕯️ **伏笔显影**（可选）· 为每条暗线赋予完整跨幕生命周期（铺陈→升温→临界→高潮→落幕）；推进与收束必须命中正文楼层原句，模型漏审不会误伤档案。
- 🧵 **弹性召回** · 档案保有 3–5 条在演伏笔，每轮只按近期语境召回 0–2 条并自动冷却，避免为了凑数生硬强拉线索。
- 🎞️ **推演质检** · 各板块拥有独立叙事辖区；遇到数量缩水、整轮复刻或伏笔漏审时，仅对缺口执行一次定向补写，不重做已经合格的内容。
- 🏙️ **尘寰群生**（可选）· 搭建世界声景墙，容纳街角吆喝、坊间八卦、各阶级圈层琐碎，为世界铺就鲜活的环境底噪同时为User扩展视角落点。

### 🎭 幕外 —— 番外小剧场

- ✍️ **独立番外短剧** · 基于当前聊天相关设定生成支线、脑洞与小剧场，支持收藏归档；不同指令可存入「剧札」复用，兼具分类管理与导入导出功能。
- 🔒 **绝不污染正文** · 仅读取当前聊天作为背景参考，内容独立成篇，既不写入正文，也不纳入推演体系，正篇与番外互不干扰。

### 🎙️ 配音 —— 多模型有声演绎

- 🔊 **多模型切换** · 支持 MiniMax、豆包语音与 ElevenLabs；连接项、声学参数、模型和音色库按供应商独立保存。
- 🧭 **豆包资源自动路由** · 同一音色库可混用官方合成 2.0、声音复刻 2.0/1.0；资源跟随音色自动切换并记忆，无需反复改全局模型。
- 🎧 **正文交互一致** · 无论选择哪个模型，正文台词提取、单句播放、双击快捷面板、重新生成、收藏和下载均沿用同一套操作。
- 🧩 **提取方案适配** · 内置跟随当前配音模型的默认模板，也可为每个模型保存独立自定义提示词。
- 🔑 **豆包新版 API Key** · 需要同时启用同仓库附带的本机中转插件，按[独立安装说明](./INSTALL-DOUBAO-APIKEY.md)操作即可。

### ⏳ 专注 —— 与故事之外的时间相处

- 🌱 **真实时间续算** · 专注、小憩与长休使用绝对截止时间，切换标签、关闭面板或浏览器后台挂起后不会漂移。
- 📚 **伴读联动** · 可把书架中的书设为本轮专注活动，计时中直接进入阅读，完成记录保留书名与阅读进度变化。
- 🧾 **轻量记录** · 今日明细与本周图表同步呈现，跨周自动清理并可导出 PNG 周报；记录独立于聊天，不增加正文负担。
- 🔔 **完成与陪伴** · 六款内置提示音或自定义外链；角色语音按聊天绑定音色，关系档由用户明确选择，情景生成不读取正文。

### 🎥 分镜 —— 让画面自然落进故事

- 🎛️ **独立连接工作台** · 在千幕内配置 NovelAI V1–V5、Banana / Gemini、GPT Image 2 / OpenAI 兼容中转、Doubao Seedream 与 ComfyUI；连接和参数按模型隔离保存，不读取或改写 SillyTavern 当前生图连接。
- 🪞 **同源生图网关** · 浏览器只请求千幕服务端插件，由插件向官方接口或自定义中转发起请求；API Key 不写入日志、数据包或聊天正文。
- 🧭 **模型选择可进可退** · 官方常用模型可直接选择；自定义或第三方中转可拉取模型、查看接口全部模型，也可手动填写模型 ID 兜底。
- 🎞️ **生成队列** · 任务最多 8 项且严格串行，可单独移除等待项或放弃活动任务收片；切换聊天后不会把旧任务误写进新聊天。
- 🎞️ **正文穿插** · 可把成片挂在当前回复或指定楼层之后；图片是正文显示层的独立兄弟节点，不改消息原文，不进入配音与正文正则扫描。
- 📹 **楼层快捷取镜** · 每条非系统正文都提供分镜入口，只把该层文本与锚点带入镜头台，不会因误触直接发起计费生成。
- 🔖 **自定义样式** · 各模型分别保存连接预设和参数样式，不跨供应商混用；成片也可把原提示词与参数安全载回镜头台复用。
- 🗂️ **形象总目录** · 同时捕获角色与 User，同一人可保存多套外观方案；档案可绑定当前聊天，切换聊天时自动回到对应方案。
- 🧾 **生成日志** · 记录模型、参数、目标楼层、耗时与失败原因；可载回镜头台、原参数再生成或复制诊断，不记录 API Key。
- 🩺 **连接预检** · 通过千幕网关检查当前接口、密钥与模型；ComfyUI 会验证服务和 API Workflow，不用收费生图代替连接测试。
- 🧰 **不替用户定画质** · Model、尺寸、Steps、CFG、Seed、Sampler 与 Scheduler 保留模型原有名称，不内置强制画质方案。
- 🧭 **按能力显示参数** · 参数区跟随当前模型切换；不支持的 Seed、Steps、反向提示词或参考图能力不会显示成无效控件。
- 🪞 **人物一致性** · 通用外观档案可参与画面整理；支持参考图的模型可直接传入档案图片，ComfyUI 则通过含 `%qianmu_reference%` 的 API Workflow 接收。
- 🗃️ **成片档案** · 支持画面/模型/人物检索、模型筛选、渐进加载、全屏看图与批量管理，长聊天也不会一次渲染全部图片。
- 📦 **分镜数据打包** · 一次迁移形象档案、参数样式、日志和本聊天成片；尽力内嵌图片并在新端交由 SillyTavern 落盘，始终排除 API Key。
- 📱 **多端稳态** · 镜头草稿自动保存，数据包导入保留 iOS 原生文件手势链；键盘焦点、低动态偏好与移动端安全区均有独立适配。

## 💡 好上手

- 🔌 **独立API**，与正文模型解耦，推演与小剧场模块均隔离运行，互不影响。
- 🧭 **零学习成本**，默认方案开箱即用，同时支持最大化自定义调整。
- 🎚️ **灵活可控**，注入项可逐项开关，不同小板块功能默认关闭，token占用与功能强度自由拿捏。

## 📦 安装

SillyTavern → **扩展（Extensions）→ 安装扩展（Install Extension）**，填入本仓库地址：

```
https://github.com/liminale1525/Omniscene.git
```

分镜生图与豆包 API Key 配音还需要启用同仓库附带的千幕服务端插件。Windows、本地 Linux、macOS、VPS 与 Docker 均可按[一键安装说明](./INSTALL-DOUBAO-APIKEY.md)操作；安装后必须重启 SillyTavern 后端服务，仅刷新网页不会加载插件。
