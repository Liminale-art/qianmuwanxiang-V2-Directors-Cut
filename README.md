# 千幕万象V2-导演剪辑版


🎬 一个 SillyTavern 第三方界面扩展，做你故事的**幕后导演**：埋线推演、递送创作灵感，不设定向日程与线性叙事路径，不替User做选择，最大化叙事自由度与演变弹性。

## ✨ 它能做什么

### 本次开发节点 · v1.59.316

- 普通阅片室的详情合集、批量归组和关键词筛选改为可搜索、有界分页的选择器，每页最多24项。相同聊天内重绘面板保留查询与页码；切换聊天或卸载时释放临时状态，旧控件失效。
- 详情修改基于完整归属做单项增减，不再从当页控件收集全量结果；页外勾选和已经不在合集列表中的旧归属仍保留并可查阅移除。旧记录超过30个归属时允许逐项减少，不静默裁剪；新增超限会明确提示。
- 批量归组先明确选择目标，再启用操作；“移出全部合集”是独立的显式选择。整批先校验，再修改；一张图超限不导致其他图片先被部分改动。记录或合集已替换时停止旧操作。
- 无新增后端部署或持久格式迁移。此处限制显示节点，不限制已保存的有效合集数量；旧分镜整包导入的120项拒绝上限和其他归属消费仍待后续统一，原件不删。
- 隔离交互、CSS合同及大库回归不代替真实ST、手机触摸、跨端保存和性能验收。Phase1未收束，视频/H3不在本节点范围。
