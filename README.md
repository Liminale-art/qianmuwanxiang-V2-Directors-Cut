# 千幕万象V2-导演剪辑版


🎬 一个 SillyTavern 第三方界面扩展，做你故事的**幕后导演**：埋线推演、递送创作灵感，不设定向日程与线性叙事路径，不替User做选择，最大化叙事自由度与演变弹性。

---

## ✨ 它能做什么

### 当前分支与安装候选

2026-11-08 按 `refactor/storyboard-modularization` 核对：千幕前后端包版本为 **1.59.484**；同版本内的改动还须核对提交与缓存标识。本文说明当前能力和限制，历史逐版本记录通过 Git 查询。

- 聊天备份读取与找回只使用 ST 原生能力，千幕独立定时备份已移除。列表按最后对话时间由近到远排列，每批展示 10 条并可继续加载，不是只读取 10 条；条目不再显示来源标签。预览只加载最后 5 层，可折叠后复用已加载内容。
- 找回按钮直接为所选角色另建副本，不再弹出确认框，不覆盖原聊天／备份、不自动打开。副本使用“角色名-QM编号”前缀及 ST 生成的日期时间，确认后移除 `imported` 后缀；成功提示为“已将此聊天备份找回至XX”。
- 可选增强服务提供“单聊天备份数上限”设置：管理员可写入 1–500，修改的是 ST 全局保留数量，重启 ST 后端生效。它不是历史备份读取上限，也不能找回已被清理的文件；只读取、预览与找回原生备份不强制安装增强服务。
- 字体目录、来源与应用选择在具备 ST 账户储存能力时静默同步；本地原件留在当前浏览器 IndexedDB，换设备需主动上传或导入字体包。内置字体仅预留注册入口，当前不附带默认原件。
- 字体包导出为含所选本机原件的压缩 ZIP，导入自动分组保存、跳过完全一致的字体并补回缺失原件；新 ZIP 不再要求按 96 MiB 手工拆包，旧 JSON 仍可导入。进度按实际处理字节显示，校验、保存和收尾未完成时不报 100%；实际大小仍受浏览器内存和存储能力约束。
- 默认字体预览为“一念起幕，万象成诗。 AaBbCc123456”，保留自定义文本，标签单行排列。字体 ZIP、进度与正文排版由前端提供；目录同步不代表字体原件已跨端恢复。

部署、验收和回退边界见[安装实测说明](INSTALL-CANDIDATE.md)，可选增强服务见[服务端安装说明](INSTALL-SERVER-PLUGIN.md)。本地隔离验证不代表 VPS、本地 ST、Docker 或实体手机已实测。

单聊记忆模块 **忆幕前端 0.8.19 · 服务端 0.8.10** 的[首次安装说明](yimu/README.md#安装与更新)另见专页；已安装忆幕时，千幕的 PM2 更新脚本及 Windows／非 PM2 安装器都会从同一提交成对同步忆幕，见服务端说明。忆幕不在 ST 扩展更新器中单独更新。支持故事续接、楼层分支、可选伴读关联及自有备份包，聊天原件由用户另行选择附带。

### 🎬 推演 —— 让世界自主运转

- 🪡 **暗线灵感池** · 推演下一幕的任务、因果链、角色动向与世界回声，提炼为线索后台注入正文，正文中自然触发取用。
- 🌍 **世界自运转** · NPC与事件各有独立运行逻辑，User可介入推动、可旁观见证、可全然不知；褪去主角光环，让故事拥有真实的生长质感。
- 🎞️ **推演质检** · 各板块拥有独立叙事辖区；缺项或结构不合格时保留有效内容供只读查看并提示缺口，不自动补写或追加模型请求。
- 🏙️ **尘寰群生**（可选）· 搭建世界声景墙，容纳街角吆喝、坊间八卦、各阶级圈层琐碎，为世界铺就鲜活的环境底噪同时为User扩展视角落点。

### 🎭 幕外 —— 番外小剧场

- ✍️ **独立番外短剧** · 基于当前聊天相关设定生成支线、脑洞与小剧场，支持收藏归档；不同指令可存入「剧札」复用，兼具分类管理与导入导出功能。
- 🔒 **绝不污染正文** · 仅读取当前聊天作为背景参考，内容独立成篇，既不写入正文，也不纳入推演体系，正篇与番外互不干扰。

### 🎙️ 配音 —— 多模型有声演绎

- 🔊 **多模型切换** · 支持 MiniMax、豆包语音与 ElevenLabs；连接项、声学参数、模型和音色库按供应商独立保存。
- 🧭 **豆包资源自动路由** · 同一音色库可混用官方合成 2.0、声音复刻 2.0/1.0；资源跟随音色自动切换并记忆，无需反复改全局模型。
- 🎧 **正文交互一致** · 无论选择哪个模型，正文台词提取、单句播放、双击快捷面板、重新生成、收藏和下载均沿用同一套操作。
- 🧩 **提取方案适配** · 内置跟随当前配音模型的默认模板，也可为每个模型保存独立自定义提示词。
- 🔑 **豆包新版 API Key** · 需要同时启用同仓库附带的本机中转插件，按[服务端插件安装与更新说明](./INSTALL-SERVER-PLUGIN.md)操作即可。

### ⏳ 专注 —— 与故事之外的时间相处

- 🌱 **真实时间续算** · 专注、小憩与长休使用绝对截止时间，切换标签、关闭面板或浏览器后台挂起后不会漂移。
- 📚 **伴读联动** · 可把书架中的书设为本轮专注活动，计时中直接进入阅读，完成记录保留书名与阅读进度变化。
- 🧾 **轻量记录** · 今日明细与本周图表同步呈现，跨周自动清理并可导出 PNG 周报；记录独立于聊天，不增加正文负担。
- 🔔 **完成与陪伴** · 六款内置提示音或自定义外链；角色语音按聊天绑定音色，关系档由用户明确选择，情景生成不读取正文。

### 🎥 分镜 —— 让画面自然落进故事

- 🎛️ **独立连接工作台** · 在千幕内配置 NovelAI V1–V5、Banana / Gemini、GPT Image 2 / OpenAI 兼容中转、Doubao Seedream 与 ComfyUI；连接和参数按模型隔离保存，不读取或改写 SillyTavern 当前生图连接。
- 🪞 **同源生图网关** · 浏览器只请求千幕服务端插件，由插件向官方接口或自定义中转发起请求；API Key 不写入日志、数据包或聊天正文。
- 🧭 **模型选择可进可退** · 官方常用模型可直接选择；自定义或第三方中转可拉取模型、查看接口全部模型，也可手动填写模型 ID 兜底。
- 🎞️ **生成队列** · 当前页运行窗口为 8 项，大批次镜头逐步入队；并发默认 2、最多 4，并继续遵守 NAI／Comfy 等渠道的连接约束。运行窗口不是整批镜头上限；刷新不自动续投未提交请求。可移除等待项，切换聊天后旧任务不得写入新聊天。
- 🎞️ **正文穿插** · 可把成片挂在当前回复或指定楼层之后；图片是正文显示层的独立兄弟节点，不改消息原文，不进入配音与正文正则扫描。
- 📹 **楼层快捷取镜** · 每条非系统正文都提供分镜入口，只把该层文本与锚点带入镜头台，不会因误触直接发起计费生成。
- 🔖 **自定义样式** · 各模型分别保存连接预设和参数样式，不跨供应商混用；有完整原配置的 NAI 成片可在核对后套用风格配置，保留当前场景与模型。
- 🗂️ **形象总目录** · 同时捕获角色与 User，同一人可保存多套外观方案；档案可绑定当前聊天，切换聊天时自动回到对应方案。
- 🧾 **生成日志** · 记录模型、参数、目标楼层、耗时与失败原因；支持展开阶段详情及发送／返回内容、查看关联插画、移出等待任务和复制诊断，不记录 API Key。
- 🩺 **连接预检** · 通过千幕网关检查当前接口、密钥与模型；ComfyUI 会验证服务和 API Workflow，不用收费生图代替连接测试。
- 🧰 **不替用户定画质** · Model、尺寸、Steps、CFG、Seed、Sampler 与 Scheduler 保留模型原有名称，不内置强制画质方案。
- 🧭 **按能力显示参数** · 参数区跟随当前模型切换；不支持的 Seed、Steps、反向提示词或参考图能力不会显示成无效控件。
- 🪞 **人物一致性** · 通用外观档案可参与画面整理；支持参考图的模型可直接传入档案图片，ComfyUI 则通过含 `%qianmu_reference%` 的 API Workflow 接收。
- 🗃️ **成片档案** · 支持画面／模型／人物等关键词检索、标签与来源筛选、合集、分页浏览、全屏看图和批量管理，长聊天也不会一次渲染全部图片。
- 📦 **分镜数据打包** · 资源联包备份本聊天配置、所选成片及原图、引用的 Vibe 原文件、工作流与候选历史、角色档案及参考原件；所需原件缺失时停止导出，不含 API Key。恢复须核对环境与身份，目前不支持不同账户名或聊天之间迁移；外部 URL 资源、模型文件与服务器授权另行保全。
- 📱 **多端稳态** · 镜头草稿自动保存，数据包导入保留 iOS 原生文件手势链；键盘焦点、低动态偏好与移动端安全区均有独立适配。
静帧、Comfy 云任务和视频的代码接入不等于各渠道真实质量、部署及费用验收完成。已受理或结果不明的任务先核对原任务；不能把前端报错、没有任务编号或更新版本当成重新付费生成的依据。原图、任务账本及恢复材料保留，具体回退限制见[安装实测说明](INSTALL-CANDIDATE.md)。

## 💡 使用方式

- 🔌 **独立API**，与正文模型解耦，推演与小剧场模块均隔离运行，互不影响。
- 🧭 **默认方案与自定义**，按模块配置连接和必要参数，再按需调整提示词与外观。
- 🎚️ **灵活可控**，注入项可逐项开关，不同小板块功能默认关闭，token占用与功能强度自由拿捏。

## 📦 安装

SillyTavern → **扩展（Extensions）→ 安装扩展（Install Extension）**，填入本仓库地址：

```
https://github.com/Liminale-art/qianmuwanxiang-V2-Directors-Cut.git
```

本页以候选分支为准；仅填仓库地址的首次 Git 安装通常取得仓库默认分支，安装后应核对实际分支。分镜生图与豆包 API Key 配音还需要启用同仓库附带的千幕服务端插件。开发测试环境以 **VPS + PM2** 为基准；Windows、本地 Linux、macOS、VPS 原生、VPS + PM2 与 Docker 的安装、更新、停服和重启边界统一写在[服务端插件安装与更新说明](./INSTALL-SERVER-PLUGIN.md)中。安装后必须重启 SillyTavern 后端服务，仅刷新网页不会加载插件。

### ST 升级与核心文件边界

千幕不要求覆盖 ST 的 `public/index.html`、`public/scripts/openai.js`、`public/scripts/power-user.js`、`public/scripts/world-info.js`、官方 Logo 或语言文件。前端放在第三方扩展目录，服务端放在独立插件目录；安装器只在备份后启用服务插件配置，不替换 ST 核心源码。

官方接口兼容以 [ST 1.19.0](https://github.com/SillyTavern/SillyTavern/releases/tag/1.19.0) 及其 [扩展上下文](https://github.com/SillyTavern/SillyTavern/blob/1.19.0/public/scripts/st-context.js) 为核对基线。旧版本缺少相关接口时保留只读兜底，不注入脚本桥接、不更改当前模型/预设、不为获取目录读取整份账号配置。

如果升级 ST 提示本地文件会被覆盖，那是被跟踪文件存在本地改动，不能靠升级千幕自动消除。请先备份并核对差异来源；例如明确标注其他插件名字的桥接补丁，需要按对应插件的升级方案处理。不要为通过更新而直接强制重置、删除补丁或忽略这些文件，否则可能丢失定制或使依赖该补丁的功能失效。

本仓提供隔离安装/升级回归及可选的 `scripts/check-st-upstream-compat.mjs`：后者只读取指定本地参考仓中的官方 1.19.0 标签并验证相关接口，不会更新实际运行的 ST。真实服务器的第三方组合、历史补丁与浏览器使用效果仍应在备份后单独验收。
