# 忆幕

SillyTavern 的单聊记忆模块。当前版本：前端 **0.8.10** · 服务端 **0.8.9**；前端入口仍按扩展加载，但更新归 **千幕万象 V2** 统一管理，不在 ST 的扩展更新器中单独更新。基本功能不依赖千幕增强服务；可选的伴读关联需要千幕 **1.59.483** 或更新版本。每份普通聊天初始关闭，不自动整理已有聊天。

前端与服务端版本独立记录：只调整界面时只需核对前端版本；服务端版本发生变化时才需要更新服务端。忆幕面板会同时显示运行中的服务端版本与所需配套版本，不再用一个“最新版本”掩盖两者差异。

本次完善菜单对齐、就地阶段总结、切片命名和故事续接。存储格式保持 **schema 7**；千幕更新命令会按同一提交同步需要的忆幕文件，已有资料保留，不需要重新导入。旧版不完整理解新增阶段策略，回退前请先导出备份。

## 安装与更新

首次安装使用忆幕安装命令；安装后更新统一使用千幕更新命令，自动同步忆幕前端与服务端，保留最近的回退资料。需要 ST 已有的 Node.js 18+、Git，以及可访问 GitHub 的网络。忆幕不是独立更新目标。

### Linux / VPS（PM2）

先进入你自己的 ST 根目录，再执行下面命令；脚本不会写入固定服务器路径。安装期间会短暂停止并重新启动所选 ST 服务，请先结束正在生成的聊天。

```bash
bash -c 'set -o pipefail; curl -fsSL https://raw.githubusercontent.com/Liminale-art/qianmuwanxiang-V2-Directors-Cut/refactor/storyboard-modularization/install-yimu.sh | bash -s -- --pm2 你的PM2服务名'
```

### Windows 本地

先停止 ST 后端，在 **ST 文件夹**打开 PowerShell，粘贴：

```powershell
& ([scriptblock]::Create((Invoke-RestMethod 'https://raw.githubusercontent.com/Liminale-art/qianmuwanxiang-V2-Directors-Cut/refactor/storyboard-modularization/install-yimu.ps1'))) --stopped
```

完成后按原方式启动 ST。无需修改 PowerShell 的全局执行策略。

安装完成后，后续更新统一使用千幕的更新命令；当前 ST 已安装忆幕时，千幕会从同一提交同步忆幕文件。不要再把忆幕当成独立更新目标。

### 非 PM2 / 容器 / 自定义配置

先停止对应 ST 实例，再在其**实际持久化的 ST 根目录**执行 Linux 命令，将 `--pm2 sillytavern` 换成 `--stopped`。自定义配置另加 `--config 配置路径`，路径须在这个 ST 根目录内。完成后按原方式启动；容器的 `plugins` 和前端扩展目录也必须持久化，不要只安装进临时容器层。

安装器只处理 `plugins/yimu`、`public/scripts/extensions/third-party/yimu` 和必要的 `enableServerPlugins` 开关，不改聊天、账户资料或千幕。遇到已有手动安装、本地修改、不明确的运行路径会停下，不强行覆盖。不要同时安装全局版和账户版忆幕。

### 怎么确认生效

刷新 ST，从聊天菜单打开**忆幕**，在**设置**页查看后端服务支持。服务正常且服务端版本达到 **0.8.9** 才算运行成功；标题版本标签显示当前前端版本，设置卡同时显示运行中的服务端版本与配套版本，更新请使用千幕更新命令。安装保留目录为 ST 根目录下的 `.yimu-install-backups`，只保留最近几份回退资料。

## 界面入口

- **概览**：双开关、手动范围、覆盖统计、四项就地展开工具，以及末尾的总结提示词与正文提取。
- **记忆**：折叠、搜索和修订切片；更多中插入自定义切片、移动和注入屏蔽；手动阶段总结。
- **设置**：API设置、正文保留层数、自动总结条件和输入栏快捷入口。普通参数改后自动保存到当前聊天，清空数值恢复默认；没有聊天时不可改聊天参数。附加功能中可单独打开**允许伴读使用自定义切片**；关闭时普通正文来源切片仍可联动，用户手写的自定义切片及混入它们的阶段总结不会送入伴读。
- **检索**：放在“记忆”和“设置”之间，查看当前关键词召回、最近候选来源，以及向量召回／重排的接入状态。向量与重排只作透明的候选增强，不改变现有注入；两张接口卡沿用伴读中心的预设、连接测试和模型拉取方式，使用 API 根地址、可选模型下拉或手动填写，API Key 显隐图标直接位于输入框内。页面不显示分数或维度，密钥仅保存在当前 ST 账户的接口设置中。候选请求共用一个可调超时，默认 **15 秒**，可在检索页设置为 **5—60 秒**；留空恢复默认。超时只触发关键词候选回退，不阻塞普通聊天；连接、拉取模型和预设结果以 ST 提示反馈，保存后预设列表立即可用。

**记忆调阅、故事续接、关联伴读、记忆备份**在概览就地展开，同排左右互斥。记忆调阅保留最后一次实际加入生成请求的记忆快照与估算用量，不把候选列表当作已使用，也不声称模型已接收。切页或收起保留未提交内容；切换聊天后重新核对来源。

“检索”页中的关键词候选只表示下一次整理可能参考的来源，不等同于已注入记忆。向量和重排各自是可选的只读增强：在当前聊天打开对应开关并填写账号级接口后才会尝试，未配置、关闭或失败均回退现有关键词路径，不阻塞正常聊天；候选数和单条正文长度沿用边界，候选接口单次等待超过设置的时限也会静默回退。候选先按当前聊天身份、故事线、时间线、知情范围和屏蔽状态过滤，重排不能新增候选或跨聊天取回内容。

界面以移动端的纵向操作为主，宽屏适度加宽但保留竖向面板，不铺满屏幕。

## 开始使用

1. 打开单聊，在概览开启**启用忆幕**。**自动总结**是独立开关；关闭自动仍可使用已有记忆和手动总结，关闭忆幕则全部停止，资料保留。普通新聊天的两个开关初始均关闭，旧版已开启的聊天保留原先自动行为。首次可确认“是否整理历史楼层”，取消后不再询问，之后用手动总结补充。
2. 默认保留最近 **5 层原文**，可自行调整。自动总结默认累计到 **50000 token** 触发，并以该值为每批目标；连接容量不足时安全分批，不另设一个重复的单次上限。完成的记忆从**下一次生成**使用，不阻塞正常聊天。来源楼层后来被编辑或删除时，旧记忆仍照常注入，但不会拿旧来源替换当前正文；记忆页只用状态色提醒你自行处理。
3. **手动总结**填写起止楼层后开始；成功且来源仍能核对时才替换该范围的自动切片。手修版保留，新结果供选择；失败的部分保留旧记忆。只截到旧切片一部分时，先显示完整范围，再点开始确认，不会悄悄扩大读取范围。已删除或暂停的切片先恢复或调整范围。ST 隐藏正文仍可总结，不改隐藏标记；即使手动整理了近期层，生成时仍保留设置数量的近期原文。
4. **阶段总结**从记忆筛选栏右侧图标就地展开，再次点击收起；选择范围后开始，与自动开关独立。手动时可点亮**包含自定义切片**，仅纳入区间内的自定义内容。自动阶段总结初始关闭，默认 **65000 token** 触发，保留最近 **10 份切片**，也可按层数或份数触发。原片和手修保留；有效阶段携带其自定义原文，不让二次压缩改掉人工含义。范围跨旧阶段时先对齐完整边界，成功后才替换自动旧阶段。
5. **附加功能 → 原文回查与补充**默认开启，之前关闭过的保持关闭；启用时才显示总结提示词的原文回查组。普通总结发现具体缺口时，才在相关切片原文中核对；每轮最多额外抽取一次，可能产生调用费用。关闭后不发起新回查。

每条新切片默认最多 **2000 字**，每条阶段总结默认最多 **3000 字**，均可调整。正文与实际时空内容一并计字，空白不计；token 随模型而异，不是固定字数换算。结果超长会保留旧记忆并提示，不硬截断、不自动付费重试，也不限制已有记忆和人工编辑。

**记忆注入上限**留空时，以 ST 正文生成连接上下文的 **1/8** 为自动预算，并核对整条请求和回复预留；不是总结 API 的容量，也不会为填满预算挤掉保留原文。

默认沿用当前 ST 连接；**设置 → API设置**还可选择**千幕API预设**或**独立连接**。千幕预设直接使用当前账户保存的连接，不额外复制密钥；独立连接支持拉取模型、流式和预设，默认温度 **1**、最大输出 **32000**、上下文 **1000000**，请按实际模型能力调整。旧的 ST 已存连接保留到用户明确切换；不会悄悄换连接。免 Key 的本地服务可留空。测试只检查模型目录，不执行总结。密钥保存在 ST 账户设置，不进入记忆或备份。

总结和整理会调用模型，可能产生费用；失败不偷偷换模型，不连续重试或反复弹窗。关闭网页后不继续执行。

整理兼顾事实与叙事质感：保留有意义的情绪过程、动作／对白和场景气氛，不将经历压成人物档案，也不为文学化补造心意或情节。阶段整理沿用同一原则；正文以当前场景和近期原文的文风为准，不模仿摘要的简写腔。更新不会自动改写已有切片或手动修订，实际文学效果仍需模型实测。

ST 聊天菜单中的“忆幕”入口始终保留。输入栏快捷入口默认隐藏，可在**设置**中开启**显示输入栏快捷入口**；此开关只控制入口显示，不会开启聊天记忆。快捷图标正常为灰蓝、执行失败为灰红，未启用或尚未就绪等其他状态为纯灰，悬停可查看具体状态。

## 自定义切片、时空与提示词

- 在切片更多中**插入自定义切片**，或点筛选栏末尾的加号。它是一份独立记忆，不是附注；插入点表示用户指定的适用楼层，不伪造原文出处。自定义切片可用前置拖柄或更多中的上下移动调整排列和适用点；普通总结切片不提供拖动。实际采用的记忆按该顺序注入，仍遵守来源与预算。
- **将此切片注入屏蔽**会变灰，保留内容。重新总结、采用候选或撤回文字不会解除屏蔽。文字撤回与撤回删除分开；重新总结失败时只提供对应失败工作的重试，不把所有待整理楼层冒充遗漏。
- 编辑直接在原切片内修改时间和正文，右上角确认或取消。重新总结时原按钮变为停止；停止后旧切片仍在，不把停止算成失败，也不会立刻自动重试。
- 新摘要会附不超过 **8 字**的短标题；旧摘要只展示摘取标题，不额外调用模型。自定义切片可编辑名称，名称与正文一起保存和撤回。
- **已删除的记忆**只保留最近 **10 条**可撤回内容，较早正文与修订会清除；保留必要来源标记，避免自动总结或旧备份把删除内容重新带回。超出撤回范围的旧稿不能恢复，但可手动选择对应正文范围重新总结。需要长期保留的内容请在删除前导出备份。
- 每片独立显示世界／时间线、日期、时段、地点、涉及角色和对应事件；同时异地、回忆、梦境分别记录。只承接有正文依据的背景；没有依据就显示未注明，不用现实时间、文件日期或排列猜剧情日期。来源变化只显示状态提醒，旧记忆仍可注入，不能据此再删除当前正文。穿越／循环按明确设定记录，不自行换算时差。标记是有据定位，不证明模型对所有题材均理解正确。
- **概览 → 总结提示词**包含切片总结／阶段总结两组，启用回查后另显示原文回查。下方的**正文提取**会先从送给总结模型的文本副本中移除 HTML 注释、状态栏和装饰标签，并支持自定义“屏蔽标签／提取标签”；提取标签找不到时保留清理后的完整正文。它不改 ST 聊天、来源指纹或楼层映射，阶段总结也不会重复清洗已有切片。实际内置规则可查看、编辑、启停、增删与排序，并支持命名预设和忆幕提示词 JSON 导入导出。下拉选择即载入，内置默认也在其中；条目正文用标题旁的确认／取消图标完成。未打开聊天时可编辑账户默认提示词。旧整理偏好保全为可编辑条目。改动从下一次整理生效，不重写旧切片；不改 ST 主对话预设，不携带密钥或正文。来源、输出格式、范围、预算与人工保护仍由程序校验。

## 续接与伴读

- 从**概览 → 故事续接**填写**续接楼层**，默认末层，再点**建立新聊天**。末层续接、早期楼层分支使用同一入口；新聊天只带设置数量的近期原文及截止前可继承的记忆，不改原聊天。
- 自定义切片按核实的适用点继承；早期分支不带入未定位的旧补充，末尾续接可带入。跨截止手修不自动裁剪；自动跨界切片只根据截止前原文整理，涉及调用时先明确确认。来源有效的屏蔽切片会保留到新聊天，继续屏蔽、不参与注入；已删除或来源无法核对的内容不带入新聊天。
- 新聊天文件以**忆幕续接**开头。成功打开后，当前页面会话内下一次返回 ST 首页会将该聊天前置一次，便于找到；不修改原消息日期或置顶设置，刷新页面或后续返回仍由 ST 排序。
- 新旧聊天独立发展，原聊天不变，不自动写回或同步。继承摘要保留来源关联、可手动修订；当前版本不跨故事自动重总结或追加原文引证。重复点击、结果未确认时按同一次操作核对，不盲目再建；此待确认操作保留在当前页面，关闭网页前应确认结果。
- 从**概览 → 关联伴读**进入，选择对应记录与**共同已读位置**，再预览并确认摘要。旧本机记录需明确确认归属。翻页本身不算共同已读；书中背景和真实交流分开标注。联动页只呈现能继续操作的记录，不要求用户处理内部来源计数。
- 关联只保存本次确认的有限摘要，不上传全书、不迁移伴读原档。摘要可随同账户忆幕跨端读取；更新范围需再次确认。正文与伴读只在精确关联的当前故事中使用有效记忆，分支不会自动继承活动关联。

## 备份与导入

从**概览 → 记忆备份**进入：

1. **导出记忆**：先询问是否一起打包相关聊天文件，可选是／否／取消，再生成 `.yimu.gz`。包内包括自动／自定义切片、阶段、时空、排列、修订、冲突及非秘密提示词配置；存在多个祖先原件时可逐项选择，不收集连接密钥或外部媒体。
2. **导入记忆**：支持多选，选好即处理，只接受忆幕格式。后台核对当前账户对应聊天并合并，相同资料跳过；确有记忆分叉保留两版，不覆盖手修、启停、API或已屏蔽／删除状态。完成时使用 ST 提示，待确认或失败项保留处理入口；未打开聊天时也能导入。
3. **未匹配或多个匹配**：仅这些异常项需要手动确认目标或取消。有主原件时，可明确选角色另建关闭忆幕的副本，不自动建聊。选择的正文不一致时只保全资料，不把旧来源冒认为已核验；尚未附带或核实的祖先来源不用于回查或原文替换，但已保存的记忆仍可作为普通注入上下文。旧导入档案保留，不因简化界面而删除。

整份聊天原件缺失时，忆幕仍保持安全边界，不会凭空补正文；但单个切片的来源发生变化不再中断正常生成，旧记忆继续注入并只在记忆页显示状态色，用户可自行重新总结、编辑或删除。来源变化的切片不参与原文替换，也不触发自动重试。伴读摘要仅作为历史保存，需重新确认关联。找回聊天保留全部消息，但不带回旧聊天的插件设置或忆幕绑定；原始聊天文件仍完整保存在备份包中。角色卡、图片和音频等外部附件需另行备份。

大文件按块上传、解压和校验。网络中断或结果未确认时，可继续同一次操作，避免重复创建；服务器或反向代理的上传容量、超时和可用磁盘仍适用。格式错误或不完整的包不会成为可用备份。

## 记忆与原文如何保全

- **日常记忆整理不改写现有 ST 聊天文件，也不另外复制一份完整原文。** 续接／分支只按明确操作新建聊天并复制近期衔接原文；备份与恢复仅在用户明确选择后携带或复制原件。原文补充仅保存楼层、指纹和引用位置；读取时从当前聊天核验还原。只能引用原段，不能凭模型返回编造来源。
- 补充是带说话者的**原文引证**，不是已证实的新事实或所有角色共同知情。来源、父摘要、开关或聊天状态变化，未完成补充直接放弃；人工修订和待处理冲突优先，不自动覆盖或换说法补回。
- 记忆切片和阶段摘要保留来源关联。来源仍可核对且通过整份请求预算的记忆，才可替换本轮请求中对应的旧原文；来源已变化的记忆只作为上下文注入，不再获得原文替换权限。近期层、未整理层和未被采用记忆对应的原文不会被忆幕删除。引证自身不能删除整层原文。
- 安全替换目前支持主聊天纯文本 Chat Completion 的普通生成、重生成、滑动重生成。不明确的请求形态、来源映射或预算一律保留原请求。计数含保守估算，不是提供商精确计费承诺；其他扩展后续改写请求仍需单独核验。
- 当前人工修订或冲突存在时，自动原文补充会保守暂停，普通聊天及其他有效记忆照常使用。原文核验能防错源，不能保证模型对所有叙事的理解无误。

## 其他记忆插件

忆幕不会把提示词里的任意 XML 标签直接当成记忆。其他插件若要提供资料，必须由宿主显式登记只读适配器；未知标签默认忽略。适配器资料先作为候选来源，不改写忆幕文档、不覆盖 ST 原文，也没有原文替换权限。适配器单独读取失败只记录该来源失败，不能阻塞忆幕自身记忆。候选会先按作用域、故事线、时间线、明确知情范围和注入屏蔽做结构过滤，再参考切片标题、场景中的世界／时间线／日期／地点／人物，以及显式登记的别名和同义词；缺少可选标记不会被强行判定为不相关。外部资料仍不会自动注入或替换忆幕内容，必须经过后续显式接入。

## 数据与回退

忆幕资料及导入档案保存在当前 ST 账户的 `.yimu` 下，跨设备访问同一 ST 账户可读取；不同实例不自动同步。当前 schema 7，旧 schema 1–6 仅在首次实际写入前迁移，并保留对应 `.schemaN.bak` 字节一致备份。打开面板不主动迁移，不调用模型补旧日期；旧未定位自定义内容保留，不猜适用位置。

关闭聊天忆幕会停止其注入与后续整理，保留已有资料。降级前先完整备份 `.yimu`，不能只换旧程序后继续写新格式；升级前备份也不能覆盖升级后的新修订。卸载程序不删除聊天。

真实叙事质量仍需单独实测；首版不做群聊或第三方摘要自动转换。正式聊天不要同时启用多套自动记忆注入。

开发构建：`node scripts/build-yimu.mjs <不存在的输出目录>`。得到独立前后端，不混入千幕发行包。自动测试使用合成账户、聊天与模型返回；不代表真实叙事质量或所有部署环境已验收。
