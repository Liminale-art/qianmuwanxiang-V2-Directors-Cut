## 后续执行顺序（从忆幕 0.8.9 开始）

当前下一节点是 **P0-C｜用户副本真实验收**。P0-A 已完成合成数据与来源异常边界证明，P0-B 已完成部署与窄屏矩阵；本轮只补矩阵和静态契约，不调用模型、不改正式聊天；真实副本的模型调用范围仍需单独确认。

1. **P0-A｜合成聊天与来源异常夹具**：覆盖正常摘要、隐藏楼层、近期原文、手修、自定义切片、阶段摘要、删除／屏蔽、续接／分支，以及正文编辑、指纹变化、缺失来源、多候选和跨账户来源。
2. **P0-B｜部署与窄屏验收矩阵**：整理本地 ST、VPS/PM2、非 PM2／容器、桌面窄屏、手机窄屏和同账户跨端的检查项；静态检查、真实导航／输入、后端版本同步分别记录。
3. **P0-C｜用户副本真实验收**：只使用用户指定的聊天副本；真实模型调用、计费范围、跨端读取另行确认，未确认前不宣称已验收。
4. **P1｜提示词与叙事质量**：先完成提示词的目标、正向示例、反例边界、格式和文学质感，再用合成样本回归流水账、关键经历、多时空和角色未知信息。
5. **P5-A｜伴读数据边界重构**：明确忆幕记忆仍按聊天独立存储在忆幕自己的聊天文档中；伴读只读取用户允许的忆幕切片投影，不回写忆幕、不覆盖 ST 正文。移除世界书同步／导出与“从主线选择总结”，保留检索词典和忆幕快捷入口；其他插件只通过显式登记的只读适配器提供候选，未知标签默认忽略。
6. **P4｜统一故事宇宙契约**：先定义只读的关系边、公共事件、叙事钩子和待确认影响；默认聊天隔离，跨线最多传播一跳，高影响事件必须由用户确认，不静默写入目标聊天。
7. **P5-B｜千幕现有页面内接入**：只在审片／预演／世界三个现有 tab 内展示紧凑状态或候选卡，所有过滤、审计和检索在后台完成；忆幕未安装时不显示入口，不影响千幕和伴读单独使用。
8. **M1｜工程与文档规整**：在功能节点稳定后再合并重复说明、归档过期验收记录、补模块索引和责任边界；不为“文件少”进行高风险批量重命名，不触碰本地私有测试资料。
9. **P6｜正式验收与发行**：前后端成对更新，完成安装器、更新器、回退目录、版本说明及多部署方式验收后再发行。

### P1｜提示词与叙事质量

- [ ] 将切片总结、阶段总结、原文回查提示词改为“明确目标 + 正向方法 + 反例边界 + 输出格式”，避免只剩规则和禁令。
- [ ] 固定事实、角色知情、时间／地点／时段、同时异地、多视角、穿越／循环时间锚点的输出要求。
- [ ] 在不档案化的前提下保留动作、对白、情绪过程和场景气氛；穿搭、物件位置、消耗等只在对后续叙事有价值时记录。
- [ ] 内置提示词与用户自定义条目继续分离；自定义条目可影响整理风格，但不能绕过来源、长度、权限和注入预算校验。
- [ ] 用合成叙事样本做“流水账／关键经历／多时空／角色未知信息”负例回归；不在本节点进行真实模型调用。

### P2｜混合候选检索

- [x] 增加独立“检索”页，放在“记忆”和“设置”之间；只展示真实的关键词召回状态、候选来源与后续能力位，不改变现有记忆注入路径。
- [x] 先做结构过滤：当前聊天、故事分支、来源有效性、时间／地点／角色、知情范围、注入屏蔽；候选只作为内部备选，不要求用户手动挑选才能正常聊天。关键词候选现在先经过统一结构合同；外部来源仍只能以显式登记的只读候选出现。
- [x] 再做关键词／别名／同义词与时间线候选召回；候选目录会读取切片标题、场景锚点和显式别名／同义词，并在容量不足时回退现有关键词与预算路径。
- [x] 建立向量候选的只读合同：提供商缺失或失败时安静回退，不保存正文副本，不把向量分数当作事实，也不越过现有结构过滤。
- [x] 向量只用于发现候选，不改变事实状态、来源状态或权限边界；向量开关按聊天独立保存，关闭、未配置或失败时稳定回退关键词路径。
- [x] 为每次候选保留来源、命中原因、版本和可回退信息。

当前界面节点已接入可选向量候选提供商：检索页提供账号级接口地址、密钥、模型与当前聊天开关；未配置、关闭或调用失败均回退关键词路径。结构过滤和关键词／别名／同义词／时空线索候选召回仍是默认路径；向量只补充候选，不改变记忆事实或来源权限。

- [x] 检索页按伴读中心模型接口统一字段与预设交互，检查链路置顶；超时改为单行“等待时间／秒”，不再向用户展示实现细节或冗余候选诊断文案。

### P3｜重排实验

- [x] 在 P2 稳定后接入可替换的重排接口，默认关闭或仅本地合成启用。
- [x] 重排仅改变当前候选顺序；未配置、关闭或失败时保留原顺序，不写入记忆、不改变来源权限。
- [x] 重排依据由外部提供商按查询、候选正文和忆幕上下文决定；忆幕不把分数当作事实。
- [x] 评估费用、延迟、模型可用性；候选数与单条正文长度沿用边界，向量候选与重排共用可调等待时间（默认 15 秒，5—60 秒），失败保留混合候选，不阻塞聊天，也不重复弹窗。
- [x] 用“相似但不应注入”的负例验证不会串线：重排不能新增候选；聊天归属、故事线、时间线、知情边界、屏蔽和失效状态均在候选层先过滤。

## 明确不做或暂缓

- 不做群聊首版支持，不做第三方摘要自动转换。
- 不恢复世界书作为忆幕／伴读的存储或导出目标；旧世界书入口在后续伴读重构节点移除。
- 不把外部插件的任意 XML 标签直接当作可信记忆；兼容采用只读、显式登记的来源适配器，未知标签默认忽略。
- 不做忆幕与分镜状态自动联动；分镜继续使用自身的外貌／状态跟随。
- 不自动把 A 聊天的私密记忆写入 B 聊天，不自动传播未采用推演或角色未知信息。
- 不新增独立宇宙页面，不把检索实现细节暴露给普通用户。
- 不恢复已经撤掉的千幕独立聊天备份、字体原件自动跨端同步或旧版重复确认流程。

## 每个节点的交付格式

1. 变更范围与不变范围。
2. 自动化测试与合成夹具结果。
3. 静态检查、真实浏览器／部署验证分别记录。
4. 失败路径、回退方式和未验证项。
