## 已实现的基础边界

- 每个普通聊天独立启用，忆幕与自动总结两个开关初始关闭；关闭自动总结可继续使用已有记忆，关闭忆幕保留资料。首版不支持群聊。
- 历史整理并入手动总结（0.8.23：不再询问历史范围，自动只从开启时已有楼层之后开始；手动按“每批层数”切批、可暂停，不受自动设置影响）、内容量分批、阶段总结、近期原文和完整请求预算已有实现。阶段依据为 token 或切片份数；旧 `floors` 读取后映射为 token，不恢复旧界面选项。
- 自动总结（`4f53d318`）：以 ST 输入框解锁判断生成结束，缺失时每 3 秒轮询、连续两次空闲才算结束；生成中不开始，并等新楼层写入聊天文件后再整理。进入聊天、启用忆幕或自动总结时已达触发值即开始并提示；上次失败的锁在重进聊天时解除并重试一次。触发值只计待整理正文 token，另可选“触发楼层数”（`triggerFloors`，与 token 阈值先到先触发，楼层触发要求待整理正文至少 2000 token）；提示词总量不参与触发。原文回查保持单一开关、默认开启。
- 自定义切片、人工修订、重总结候选、冲突双方、删除最近十条可撤回、注入屏蔽及迟到保护已有实现。ST 隐藏正文仍可整理，不改变隐藏标记。
- 原文回查只处理具体缺口；引证保留来源指针，不复制整份聊天，不获取整层原文替换权限。来源、父版本、设置或聊天变化时迟到结果不写入。
- 单个切片来源变化后，旧记忆仍可静默作为上下文注入，但不得替换当前正文；失效来源也不能进入新检索候选或续接。删除／屏蔽不会被召回、重排或导入解除。整份来源不可用、来源未核验与单片变化分别处理，不能简写成“一切失效记忆都不注入”或“一切来源检查都取消”。
- 续接／分支只继承截止前允许的记忆和近期原文，新旧聊天独立。自有 `.yimu.gz` 备份可选原件；导入保留冲突，来源不明不冒认，另建聊天不覆盖原件。
- 伴读桥只读已确认的有限投影，自定义分享默认关闭；关闭时混入自定义的阶段整体不共享，避免截出失真片段，不回写忆幕或 ST 正文。
- 当前有 **导览／记忆／检索／设置四个主页面**；记忆调阅、故事续接、关联伴读、记忆备份是导览内工具。主题、字体、标签、就地编辑和面板几何已有实现。
- 正文提取只处理发给总结模型的文本副本；默认去 HTML 注释并提取 `<content>`，无提取标签时保留处理后的全文。屏蔽标签初始为空，由用户明确添加，不默认删除思考、状态栏或任意装饰标签。

该节点放在向量／重排成功链修复、基础总结质量可以重复验收之后，先做数据契约与回归夹具，再进入运行时实现。它把长期记忆的“如何更新、如何关联、如何证明仍然有效”单独建立起来，不改变当前聊天默认隔离和来源优先级。首轮保持轻量，不引入完整图数据库。

- [ ] **P3.5-B 条目维护与关联**（A-MEM 方向）：为条目增加可重建的描述、关键词、标签、`relatedIds` 与关联原因。新条目可以提出相关候选与链接，由来源校验和人工修订决定是否写入；人工修改拥有最高优先级，原文指纹和版本链始终保留。首轮只服务候选扩展／重排，不直接改写事实正文或改变注入权限。
- [ ] **P3.5-C 记忆能力评估**（MemoryAgentBench 方向）：建立“准确召回、即时更新、长程承接、选择性遗忘”四组可重复夹具，覆盖新增事实、冲突事实、未知信息、删除／屏蔽后不再召回和跨阶段续接。首轮可落在 `tests/yimu-memory-bench.test.mjs`，记录 Recall@k／精确度、来源忠实度、陈旧召回率、更新延迟、token 与费用；评估结果进入 P6 前的回归门槛。
- [ ] **共同边界与降级**：不把推测、候选影响或角色未见信息写成事实；数据冲突时保留不确定状态并回退到可核对来源；新维护层失败时继续使用现有切片与原文链，不阻断基本总结。

向量与重排共用 **15 秒、可调 5—60 秒** 的设置值，但每个请求分别计时，不是整轮总等待上限。总结连接测试仅查模型目录；向量／重排连接测试向 `embeddings`／`rerank` 发送固定合成文本，可能产生费用。模型目录可用不证明候选处理成功。

请求路线分别核验：总结自定义 API／千幕 API 预设经 ST 代理，失败不回退浏览器直连；向量／重排测试与正式调用当前由浏览器直接访问配置地址，需浏览器可达并允许跨域。若首次自动添加 Bearer 前缀后收到 401／403，可在同一次调用的超时范围内使用原始 Key 格式兼容重试一次；这不是模型换线或无界失败重试。
