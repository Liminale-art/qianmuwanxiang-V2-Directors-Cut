# 忆幕／千幕后续开发任务清单

更新：2026-10-29  
基线：忆幕 0.8.5，千幕 1.59.483-yimu-081-1
性质：开发交接与验收清单，不是安装说明；未勾选项目不得在界面或版本说明中标为已完成。

## 当前已落地的首版边界

- [x] 单聊独立记忆；每个聊天单独启用，默认不自动合并，不支持群聊。
- [x] “启用忆幕”和“自动总结”分开控制；已有记忆可在关闭自动总结时继续使用。
- [x] 首次历史范围确认、手动总结、自动分批整理、阶段总结与近期原文保留。
- [x] 记忆切片、阶段摘要、自定义切片、手动修订、候选冲突、删除保留十条及注入屏蔽。
- [x] 正文来源楼层／指纹核验；ST 隐藏楼层仍可参加整理，不改隐藏标记。
- [x] 原文级受控回查开关；只在缺口出现时使用，失败保留旧记忆，不把补充冒充新事实。
- [x] 续接／分支、伴读关联、自有 `.yimu.gz` 备份与导入；原聊天不被覆盖。
- [x] 忆幕前端以移动端纵向面板为基准，概览／记忆／设置与四项就地展开工具已统一到现有千幕主题体系。
- [x] 字体库：新版 ZIP 不设产品级元数据或字体原件字节上限；预览字号与正文排版隔离，ST 楼层编辑跟随正文排版字号。

以上是代码与本地合成测试结论，不等同于 VPS、手机、跨端账户存储或真实长聊天验收。

## 本次节点｜正文记忆联动最小闭环（2026-10-29）

- [x] 忆幕设置增加“允许伴读使用自定义切片”，默认关闭；普通正文来源切片的联动路径不受影响。
- [x] 自定义切片不共享时，任何混入自定义内容的阶段总结整体不共享，避免把一段不可拆的总结截成失真的半段。
- [x] 设置优先级明确：当前聊天有明确值时以当前聊天为准，否则使用默认设置；关闭后不改变忆幕自身的整理与注入。
- [x] 伴读关联页移除共有条数、来源失效条数等内部诊断展示，保留用户需要的标题与共同已读位置。
- [x] 加入契约测试：默认隔离、显式开启、混合阶段整体隔离，以及页面不显示内部来源计数。
- [x] 来源楼层发生编辑或删除后，旧记忆仍可静默注入；只保留状态边框与处理入口，不再自动重试，也不允许旧来源替换当前正文。

本节点只改变“送往伴读的内容边界”，不改变忆幕存储、正文指纹核验、原文回查和忆幕自身注入；未进行真实模型调用或 VPS/手机验收。

## 节点顺序

### P0｜真实验收准备与边界夹具（当前节点，不调用模型）

- [x] 固定本清单，标明“本地验证”和“真实验收”两种状态。
- [ ] 增加合成聊天夹具：正常摘要、隐藏楼层、近期原文、手修、自定义切片、阶段摘要、删除／屏蔽、续接与分支。
- [ ] 增加来源异常夹具：楼层指纹变化、缺失文件、多个候选聊天、未匹配聊天、跨账户资料。
- [x] 建立外部记忆只读适配契约与合成夹具：必须显式登记来源；未知 XML／标签不解析；外部资料不拥有原文替换权限。
- [ ] 增加验收矩阵：本地 ST、VPS/PM2、非 PM2 或容器、桌面窄屏、手机窄屏、同账户跨端。
- [ ] 首轮真实验收只使用用户指定的聊天副本；不改正式聊天，不自动调用模型，不进行付费测试。

验收门槛：所有夹具能证明来源变化时旧记忆仍注入但不替换当前正文、隐藏楼层仍可整理、续接只带截止楼层之前的有效内容、失败不会伪报成功。

### P1｜提示词与叙事质量

- [ ] 将切片总结、阶段总结、原文回查提示词改为“明确目标 + 正向方法 + 反例边界 + 输出格式”，避免只剩规则和禁令。
- [ ] 固定事实、角色知情、时间／地点／时段、同时异地、多视角、穿越／循环时间锚点的输出要求。
- [ ] 在不档案化的前提下保留动作、对白、情绪过程和场景气氛；穿搭、物件位置、消耗等只在对后续叙事有价值时记录。
- [ ] 内置提示词与用户自定义条目继续分离；自定义条目可影响整理风格，但不能绕过来源、长度、权限和注入预算校验。
- [ ] 用合成叙事样本做“流水账／关键经历／多时空／角色未知信息”负例回归；不在本节点进行真实模型调用。

### P2｜混合候选检索

- [x] 增加独立“检索”页，放在“记忆”和“设置”之间；只展示真实的关键词召回状态、候选来源与后续能力位，不改变现有记忆注入路径。
- [x] 先做结构过滤：当前聊天、故事分支、来源有效性、时间／地点／角色、知情范围、注入屏蔽；候选只作为内部备选，不要求用户手动挑选才能正常聊天。关键词候选现在先经过统一结构合同；外部来源仍只能以显式登记的只读候选出现。
- [x] 再做关键词／别名／同义词与时间线候选召回；候选目录会读取切片标题、场景锚点和显式别名／同义词，并在容量不足时回退现有关键词与预算路径。
- [x] 建立向量候选的只读合同：提供商缺失或失败时安静回退，不保存正文副本，不把向量分数当作事实，也不越过现有结构过滤。
- [x] 向量只用于发现候选，不改变事实状态、来源状态或权限边界；向量开关按聊天独立保存，关闭、未配置或失败时稳定回退关键词路径。
- [x] 为每次候选保留来源、命中原因、版本和可回退信息。

当前界面节点已接入可选向量候选提供商：检索页提供账号级接口地址、密钥、模型与当前聊天开关；未配置、关闭或调用失败均回退关键词路径。结构过滤和关键词／别名／同义词／时空线索候选召回仍是默认路径；向量只补充候选，不改变记忆事实或来源权限。下一节点再进入独立重排。

### P3｜重排实验

- [ ] 在 P2 稳定后接入可替换的重排接口，默认关闭或仅本地合成启用。
- [ ] 重排依据包含叙事时间、地点、参与者、关系状态、近期性、用户偏好和阶段位置。
- [ ] 评估费用、延迟、模型可用性；失败保留混合候选，不阻塞聊天，也不重复弹窗。
- [ ] 用“相似但不应注入”的负例验证不会串线。

### P4｜统一故事宇宙契约

- [ ] 千幕侧定义 `relationship_edge`、`universe_event`、`narrative_hook`、`impact_candidate`，带版本、来源、作用域、知情边界和撤回关系。
- [ ] 默认聊天彼此独立；只有用户主动建立关系边后才允许共享明确交集。
- [ ] 事件账本区分已发生事实、候选影响、未兑现钩子、公共背景音；不为追求闭环强行触发或收束。
- [ ] 跨线传播最多一跳；高影响事件必须待确认，不能静默写入目标聊天。

### P5｜现有千幕页面内接入

- [ ] 只在现有“审片／预演／世界”中增加紧凑状态或候选卡，不新增“宇宙”tab。
- [ ] 审片显示来源和待确认余波，预演显示候选钩子，世界显示关系边与公共事件。
- [ ] 所有检索、过滤、审计在后台完成；空数据不占位，不阻塞正常聊天。
- [ ] 忆幕只读取已确认的公共世界／关系快照，不反向改写另一条聊天或正文。

### P6｜正式验收与发行

- [ ] 前后端版本成对更新，安装器、更新器、回退目录和部署说明同步。
- [ ] 用中等长度聊天副本完成真实整理、失败重试、回查、续接、备份导入导出和跨端读取。
- [ ] 分别核对桌面、VPS/PM2、非 PM2/容器、手机窄屏；静态检查与真实导航／输入／模型调用分开记录。
- [ ] 真实模型调用、计费范围和跨端效果需单独确认；未确认前不在发布说明中宣称“已验收”。

## 明确不做或暂缓

- 不做群聊首版支持，不做第三方摘要自动转换。
- 不恢复世界书作为忆幕／伴读的存储或导出目标；旧世界书入口在后续伴读重构节点移除。
- 不把外部插件的任意 XML 标签直接当作可信记忆；兼容采用只读、显式登记的来源适配器，未知标签默认忽略。
- 不做忆幕与分镜状态自动联动；分镜继续使用自身的外貌／状态跟随。
- 不自动把 A 聊天的私密记忆写入 B 聊天，不自动传播未采用推演或角色未知信息。
- 不新增独立宇宙页面，不把检索实现细节暴露给普通用户。
- 不恢复已经撤掉的千幕独立聊天备份、字体原件自动跨端同步或旧版重复确认流程。

## 每个节点的交付格式

1. 变更范围与不变范围。
2. 自动化测试与合成夹具结果。
3. 静态检查、真实浏览器／部署验证分别记录。
4. 失败路径、回退方式和未验证项。
5. 节点通过后单独提交并推送；未通过不把后续节点混入同一提交。
